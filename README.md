#Digital Library - Menibuks by Dilla Salsabila

Sistem perpustakaan digital (praktikum Full Stack Web Development).

- backend/  : Laravel REST API (MySQL, Sanctum)
- design/   : ERD, DFD, mockup Figma, dan prototipe HTML
- frontend/ : dikerjakan setelah UTS

Desain Figma: https://www.figma.com/design/dadSus7YMKKLKZWo1DSKS8/MENIBUKS-DIGITAL-LIBRARY-DYLA

Menjalankan backend: composer install, atur .env (MySQL), php artisan migrate:fresh --seed, php artisan serve
